# sql-cli v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a single Go binary `sql-cli` that lets AI agents query MySQL via four subcommands, emitting structured JSON envelopes with one-to-one error-code-to-exit-code mapping and a default read-only posture.

**Architecture:** A from-scratch Go module rooted at the repo, organised as `cmd/sql-cli/main.go` plus an `internal/` tree. Each capability is its own package: `output` (envelope), `config` (DSN), `safety` (SQL scanner), `mysqldrv` (driver + classifier), `command` (subcommand handlers), `cli` (router). No driver interface in v1.0 — the package boundary is the extension point. MySQL is only touched at runtime and in testcontainers-gated integration tests.

**Tech Stack:** Go 1.22+, `github.com/go-sql-driver/mysql` v1.8+, `github.com/testcontainers/testcontainers-go/modules/mysql` v0.30+ (test-only), `database/sql` stdlib.

**Spec source of truth:** [openspec/changes/v1-mysql-cli/](openspec/changes/v1-mysql-cli/) — proposal, design, 6 capability specs, tasks.

```go
package output

import (
    "encoding/json"
    "io"
)

// ErrorCode is one of the nine machine-readable failure categories.
type ErrorCode string

const (
    CodeConfig         ErrorCode = "CONFIG_ERROR"
    CodeConnection     ErrorCode = "CONNECTION_ERROR"
    CodeAuth           ErrorCode = "AUTH_ERROR"
    CodePermission     ErrorCode = "PERMISSION_DENIED"
    CodeSafety         ErrorCode = "SAFETY_BLOCKED"
    CodeQuery          ErrorCode = "QUERY_ERROR"
    CodeTimeout        ErrorCode = "TIMEOUT"
    CodeInternal       ErrorCode = "INTERNAL_ERROR"
)

// Column describes one result-set column.
type Column struct {
    Name string `json:"name"`
    Type string `json:"type"`
}

// Envelope is the success shape on stdout.
type Envelope struct {
    OK        bool     `json:"ok"`
    Columns   []Column `json:"columns"`
    Rows      [][]any  `json:"rows"`
    RowCount  int      `json:"row_count"`
    ElapsedMs int64    `json:"elapsed_ms"`
}

// WriteSuccess serialises a success envelope to w.
func WriteSuccess(w io.Writer, cols []Column, rows [][]any, rowCount int, elapsedMs int64) error {
    env := Envelope{OK: true, Columns: cols, Rows: rows, RowCount: rowCount, ElapsedMs: elapsedMs}
    return json.NewEncoder(w).Encode(env)
}
```

```go
package output

import (
    "encoding/json"
    "io"
)

type ErrorCode string

const (
    CodeConfig     ErrorCode = "CONFIG_ERROR"
    CodeConnection ErrorCode = "CONNECTION_ERROR"
    CodeAuth       ErrorCode = "AUTH_ERROR"
    CodePermission ErrorCode = "PERMISSION_DENIED"
    CodeSafety     ErrorCode = "SAFETY_BLOCKED"
    CodeQuery      ErrorCode = "QUERY_ERROR"
    CodeTimeout    ErrorCode = "TIMEOUT"
    CodeInternal   ErrorCode = "INTERNAL_ERROR"
)

type Column struct {
    Name string `json:"name"`
    Type string `json:"type"`
}

type Envelope struct {
    OK        bool     `json:"ok"`
    Columns   []Column `json:"columns"`
    Rows      [][]any  `json:"rows"`
    RowCount  int      `json:"row_count"`
    ElapsedMs int64    `json:"elapsed_ms"`
}

type Error struct {
    Code    ErrorCode      `json:"code"`
    Message string         `json:"message"`
    Details map[string]any `json:"details,omitempty"`
}

type FailureEnvelope struct {
    OK    bool  `json:"ok"`
    Error Error `json:"error"`
}

// WriteSuccess serialises a success envelope to w.
func WriteSuccess(w io.Writer, cols []Column, rows [][]any, rowCount int, elapsedMs int64) error {
    env := Envelope{OK: true, Columns: cols, Rows: rows, RowCount: rowCount, ElapsedMs: elapsedMs}
    return json.NewEncoder(w).Encode(env)
}

// WriteFailure serialises a failure envelope to w. It enforces the per-code
// details schema: CONFIG_ERROR and INTERNAL_ERROR never carry details;
// SAFETY_BLOCKED requires `keyword`; the MySQL-flavoured codes require
// `mysql_error_code`. Unknown keys are dropped.
func WriteFailure(w io.Writer, code ErrorCode, message string, details map[string]any) error {
    cleaned := filterDetails(code, details)
    env := FailureEnvelope{OK: false, Error: Error{Code: code, Message: message, Details: cleaned}}
    return json.NewEncoder(w).Encode(env)
}

func filterDetails(code ErrorCode, in map[string]any) map[string]any {
    if in == nil {
        return nil
    }
    switch code {
    case CodeConfig, CodeInternal:
        return nil
    case CodeSafety:
        if kw, ok := in["keyword"].(string); ok && kw != "" {
            out := map[string]any{"keyword": kw}
            if sql, ok := in["sql"].(string); ok { out["sql"] = sql }
            return out
        }
        return nil
    case CodeAuth, CodePermission, CodeQuery, CodeTimeout, CodeConnection:
        if codeNum, ok := in["mysql_error_code"].(uint16); ok {
            out := map[string]any{"mysql_error_code": codeNum}
            if sql, ok := in["sql"].(string); ok { out["sql"] = sql }
            return out
        }
        return nil
    }
    return nil
}
```

```go
package output

import (
    "database/sql"
    "time"
)

// toJSONValues converts one row of scanned values into JSON-friendly values.
//   nil      -> nil
//   int*     -> float64
//   float*   -> float64
//   []byte   -> string (utf-8 best-effort)
//   string   -> string
//   time.Time -> RFC3339 string
//   bool     -> bool
//   other    -> fallback to fmt.Stringer / string conversion
func toJSONValues(row []any) ([]any, error) {
    out := make([]any, len(row))
    for i, v := range row {
        switch x := v.(type) {
        case nil:
            out[i] = nil
        case int:
            out[i] = float64(x)
        case int8:
            out[i] = float64(x)
        case int16:
            out[i] = float64(x)
        case int32:
            out[i] = float64(x)
        case int64:
            out[i] = float64(x)
        case uint:
            out[i] = float64(x)
        case uint8:
            out[i] = float64(x)
        case uint16:
            out[i] = float64(x)
        case uint32:
            out[i] = float64(x)
        case uint64:
            out[i] = float64(x)
        case float32:
            out[i] = float64(x)
        case float64:
            out[i] = x
        case bool:
            out[i] = x
        case []byte:
            out[i] = string(x)
        case string:
            out[i] = x
        case time.Time:
            out[i] = x.UTC().Format(time.RFC3339)
        default:
            // Fallback for named types or unknown wrappers: try a string.
            out[i] = sql.NullString{String: defaultString(v), Valid: v != nil}.String
        }
    }
    return out, nil
}

func defaultString(v any) string {
    if s, ok := v.(stringer); ok { return s.String() }
    if s, ok := v.(interface{ String() string }); ok { return s.String() }
    return ""
}

type stringer interface{ String() string }
```

```go
package config

import (
    "errors"
    "fmt"
    "net/url"
    "strings"
)

// Validate parses a mysql:// DSN and returns the raw DSN unchanged on success.
// On any failure it returns a non-nil error suitable for surfacing as
// CONFIG_ERROR to the caller.
func Validate(dsn string) (string, error) {
    if strings.ContainsAny(dsn, "\n\r") {
        return "", errors.New("DSN contains illegal control character (\\n or \\r)")
    }
    u, err := url.Parse(dsn)
    if err != nil {
        return "", fmt.Errorf("DSN is not a valid URL: %w", err)
    }
    if u.Scheme != "mysql" {
        return "", fmt.Errorf("unsupported DSN scheme %q (only mysql:// is accepted)", u.Scheme)
    }
    if u.Host == "" {
        return "", errors.New("DSN is missing a host component")
    }
    // url.Parse places "host:3306" into Hostname() / Port(). Require an
    // explicit port segment; "" is not acceptable.
    if u.Port() == "" {
        return "", errors.New("DSN is missing the port segment (e.g. :3306)")
    }
    return dsn, nil
}
```

```go
package config

import "errors"

// Resolve picks the DSN from the first non-empty source. flag takes priority
// over env. Returns CONFIG_ERROR on absence.
func Resolve(flagDSN, envDSN string) (string, error) {
    if flagDSN != "" {
        return Validate(flagDSN)
    }
    if envDSN != "" {
        return Validate(envDSN)
    }
    return "", errors.New("no DSN provided; set --dsn or SQL_CLI_DSN")
}
```

```go
// The 11 write keywords we block. Stored uppercase; matching is case-insensitive.
var writeKeywords = []string{
    "INSERT", "UPDATE", "DELETE", "DROP", "CREATE", "ALTER",
    "TRUNCATE", "GRANT", "REVOKE", "RENAME", "REPLACE",
}

var keywordSet = func() map[string]bool {
    m := make(map[string]bool, len(writeKeywords))
    for _, k := range writeKeywords { m[k] = true }
    return m
}()

// Scan walks the SQL string and returns every detected write keyword in
// canonical uppercase form. The result is sorted lexicographically.
func Scan(sql string) []string {
    var hits []string
    i := 0
    inString := false
    inLineComment := false
    inBlockComment := false
    for i < len(sql) {
        c := sql[i]
        // Two-character lookahead for comment markers.
        if !inString && !inLineComment && i+1 < len(sql) {
            two := sql[i : i+2]
            if two == "/*" { inBlockComment = true; i += 2; continue }
            if two == "--" { inLineComment = true; i += 2; continue }
        }
        if inBlockComment {
            if c == '*' && i+1 < len(sql) && sql[i+1] == '/' {
                inBlockComment = false; i += 2; continue
            }
            i++; continue
        }
        if inLineComment {
            if c == '\n' { inLineComment = false }
            i++; continue
        }
        if inString {
            if c == '\'' {
                if i+1 < len(sql) && sql[i+1] == '\'' {
                    // Escaped quote ''
                    i += 2; continue
                }
                inString = false; i++; continue
            }
            i++; continue
        }
        if c == '\'' { inString = true; i++; continue }

        if isWordByte(c) {
            start := i
            for i < len(sql) && isWordByte(sql[i]) { i++ }
            word := strings.ToUpper(sql[start:i])
            if keywordSet[word] { hits = append(hits, word) }
            continue
        }
        i++
    }
    sort.Strings(hits)
    return hits
}

func isWordByte(b byte) bool {
    r := rune(b)
    return unicode.IsLetter(r) || unicode.IsDigit(r) || b == '_'
}
```

```go
package mysqldrv

import (
    "errors"
    "fmt"
    "net/url"
    "sort"
    "strings"
)

// mysqlURLToDriverDSN converts a mysql:// URL into the DSN form expected by
// the github.com/go-sql-driver/mysql driver: user:pass@tcp(host:port)/db?params.
func mysqlURLToDriverDSN(raw string) (string, error) {
    u, err := url.Parse(raw)
    if err != nil { return "", fmt.Errorf("parse: %w", err) }
    if u.Scheme != "mysql" {
        return "", errors.New("unsupported scheme")
    }
    if u.Port() == "" {
        return "", errors.New("port segment is required")
    }
    var b strings.Builder
    if u.User != nil {
        b.WriteString(u.User.Username())
        if pw, ok := u.User.Password(); ok {
            b.WriteByte(':'); b.WriteString(pw)
        }
    }
    b.WriteString("@tcp(")
    b.WriteString(u.Hostname()); b.WriteByte(':'); b.WriteString(u.Port())
    b.WriteString(")/")
    b.WriteString(strings.TrimPrefix(u.Path, "/"))
    if u.RawQuery != "" {
        // url.Values.Encode sorts keys.
        v, _ := url.ParseQuery(u.RawQuery)
        keys := make([]string, 0, len(v))
        for k := range v { keys = append(keys, k) }
        sort.Strings(keys)
        parts := make([]string, 0, len(keys))
        for _, k := range keys {
            vs := v[k]
            if len(vs) == 0 {
                parts = append(parts, k)
            } else {
                for _, val := range vs {
                    parts = append(parts, fmt.Sprintf("%s=%s", k, val))
                }
            }
        }
        if len(parts) > 0 {
            b.WriteByte('?'); b.WriteString(strings.Join(parts, "&"))
        }
    }
    return b.String(), nil
}
```

```go
package mysqldrv

import (
    "context"
    "errors"
    "net"
    "strings"

    "github.com/go-sql-driver/mysql"
    "sql-cli/internal/output"
)

// ClassifyError maps a raw error returned by the driver (or context) into
// (code, humanMessage, details). For INTERNAL_ERROR the details map is nil;
// the output layer enforces the no-details schema for that code.
func ClassifyError(err error, sqlText string) (output.ErrorCode, string, map[string]any) {
    if err == nil { return "", "", nil }
    if errors.Is(err, context.DeadlineExceeded) {
        return output.CodeTimeout, "query execution exceeded the time limit", map[string]any{"sql": sqlText}
    }
    var me *mysql.MySQLError
    if errors.As(err, &me) {
        details := map[string]any{"mysql_error_code": uint16(me.Number), "sql": sqlText}
        switch me.Number {
        case 1045:
            return output.CodeAuth, "access denied: "+me.Message, details
        case 1044, 1142:
            return output.CodePermission, "permission denied: "+me.Message, details
        case 3024:
            return output.CodeTimeout, "query interrupted: "+me.Message, details
        case 1064, 1146:
            return output.CodeQuery, "query error: "+me.Message, details
        default:
            // Other client errors (other 1xxx codes) are query errors.
            if me.Number < 2000 {
                return output.CodeQuery, "query error: "+me.Message, details
            }
            // Truly unknown — INTERNAL_ERROR with nil details.
            return output.CodeInternal, "internal error: "+me.Message, nil
        }
    }
    // Network-level failures (DNS, refused, reset) → CONNECTION_ERROR.
    var ne net.Error
    if errors.As(err, &ne) {
        return output.CodeConnection, "connection error: "+err.Error(), nil
    }
    if isConnectionString(err) {
        return output.CodeConnection, "connection error: "+err.Error(), nil
    }
    return output.CodeInternal, "internal error: "+err.Error(), nil
}

func isConnectionString(err error) bool {
    s := err.Error()
    return strings.Contains(s, "connection refused") ||
        strings.Contains(s, "no such host") ||
        strings.Contains(s, "i/o timeout")
}
```

```go
var identRe = regexp.MustCompile(`^[A-Za-z0-9_]+$`)

// ValidateIdent checks that s is a single MySQL identifier. Returns nil on
// success, an error suitable for CONFIG_ERROR otherwise.
func ValidateIdent(s string) error {
    if !identRe.MatchString(s) {
        return errors.New("identifier must match [A-Za-z0-9_]+")
    }
    return nil
}

// ValidateDBTable checks the <db>.<table> form used by `describe`. Exactly
// one dot, both halves non-empty, both halves identifier-shaped.
func ValidateDBTable(s string) error {
    if !identRe.MatchString(s) {
        return errors.New("argument must match <db>.<table> with [A-Za-z0-9_]+ on each side")
    }
    if len(s) == 0 || s[0] == '.' || s[len(s)-1] == '.' {
        return errors.New("argument must not start or end with a dot")
    }
    // Count dots; reject anything but exactly one.
    n := 0
    for i := 0; i < len(s); i++ { if s[i] == '.' { n++ } }
    if n != 1 {
        return errors.New("argument must contain exactly one dot")
    }
    return nil
}
```

```go
// Tables runs SHOW TABLES FROM `<db>` after whitelist-validating db.
func Tables(ctx context.Context, db DB, dbName string, out outputWriter) error {
    if err := ValidateIdent(dbName); err != nil {
        return outputError(output.CodeConfig, "tables: "+err.Error(), nil)
    }
    start := time.Now()

    if err != nil { return err }
    defer rows.Close()
    cols, scanned, count, err := drainRows(rows)
    if err != nil { return err }
    return out.WriteSuccess(cols, scanned, count, elapsedMs(start))

// drainRows is shared across handlers.
func drainRows(rows *sql.Rows) ([]output.Column, [][]any, int, error) {
    types, err := rows.ColumnTypes()
    if err != nil { return nil, nil, 0, err }
    cols := make([]output.Column, len(types))
    for i, ct := range types {
        cols[i] = output.Column{Name: ct.Name(), Type: ct.DatabaseTypeName()}
    }
    var result [][]any
    for rows.Next() {
        raw := make([]any, len(cols))
        ptrs := make([]any, len(cols))
        for i := range raw { ptrs[i] = &raw[i] }
        if err := rows.Scan(ptrs...); err != nil { return nil, nil, 0, err }
        converted, err := toJSONValues(raw)
        if err != nil { return nil, nil, 0, err }
        result = append(result, converted)
    }
    if err := rows.Err(); err != nil { return nil, nil, 0, err }
    return cols, result, len(result), nil
}

func elapsedMs(start time.Time) int64 {
    d := time.Since(start)
    if d < 0 { return 0 }
    return d.Milliseconds()
}
```

```go
package command

import (
    "context"
    "fmt"
    "io"
    "os"
    "strings"
    "time"

    "sql-cli/internal/mysqldrv"
    "sql-cli/internal/output"
    "sql-cli/internal/safety"
)

const stdinReadTimeout = 30 * 1_000_000_000 // 30s in ns
const queryExecTimeout = 30 * 1_000_000_000

// Query executes the SQL after running the safety scan. If sqlText is "" the
// caller is expected to have set readFromStdin.
func Query(ctx context.Context, db DB, sqlText string, readFromStdin bool, out outputWriter, stderr io.Writer) error {
    if readFromStdin {
        s, err := readStdin(stderr)
        if err != nil { return err }
        sqlText = s
    }
    if strings.TrimSpace(sqlText) == "" {
        return outputError(output.CodeConfig, "query: SQL must be non-empty", nil)
    }
    if hits := safety.Scan(sqlText); len(hits) > 0 {
        return outputError(output.CodeSafety,
            fmt.Sprintf("Write keyword %q detected", hits[0]),
            map[string]any{"keyword": hits[0], "sql": sqlText})
    }
    start := time.Now()
    execCtx, cancel := context.WithTimeout(ctx, queryExecTimeout)
    defer cancel()
    rows, err := db.QueryContext(execCtx, sqlText)
    if err != nil {
        code, msg, details := mysqldrv.ClassifyError(err, sqlText)
        return outputError(code, msg, details)
    }
    defer rows.Close()
    cols, scanned, count, err := drainRows(rows)
    if err != nil {
        code, msg, details := mysqldrv.ClassifyError(err, sqlText)
        return outputError(code, msg, details)
    }
    _ = start
    return out.WriteSuccess(cols, scanned, count, elapsedMs(time.Now().Add(-1)))
}

func readStdin(_ io.Writer) (string, error) {
    type result struct {
        data []byte
        err  error
    }
    ch := make(chan result, 1)
    go func() {
        data, err := io.ReadAll(os.Stdin)
        ch <- result{data, err}
    }()
    select {
    case r := <-ch:
        if r.err != nil { return "", outputError(output.CodeInternal, "stdin read: "+r.err.Error(), nil) }
        return string(r.data), nil
    case <-time.After(stdinReadTimeout):
        return "", outputError(output.CodeTimeout, "stdin read timed out after 30s", nil)
    }
}
```

```go
package cli

import (
    "fmt"
    "io"
    "os"

    "sql-cli/internal/output"
)

// Router parses global flags and dispatches to a subcommand handler.
type Router struct {
    Stdout io.Writer
    Stderr io.Writer
    DSN    string // resolved before Run is called
}

// Warn writes a human-facing line to stderr; it MUST NOT touch stdout.
func (r *Router) Warn(format string, args ...any) {
    fmt.Fprintf(r.Stderr, format+"\n", args...)
}

// Run dispatches on args[0] to one of the four subcommands. The first element
// of args is the program name; args[1] is the subcommand.
func (r *Router) Run(args []string) int {
    if len(args) < 2 {
        writeJSONError(r.Stdout, output.CodeConfig, "a subcommand is required (databases | tables | describe | query)")
        return ExitCodeFor(output.CodeConfig)
    }
    sub := args[1]
    switch sub {
    case "databases", "tables", "describe", "query":
        return r.dispatch(sub, args[2:])
    case "--help", "-h":
        PrintHelp(r.Stdout); return 0
    case "--version", "-v":
        PrintVersion(r.Stdout); return 0
    default:
        writeJSONError(r.Stdout, output.CodeConfig, fmt.Sprintf("unknown subcommand %q", sub))
        return ExitCodeFor(output.CodeConfig)
    }
}

func (r *Router) dispatch(sub string, rest []string) int {
    // Wire-up is done in main.go: it builds a *sql.DB and constructs the
    // command-handler closures that close over it. To keep router pure we
    // register handlers via a package-level map in main.
    if h, ok := handlers[sub]; ok { return h(r, rest) }
    writeJSONError(r.Stdout, output.CodeInternal, "no handler registered for "+sub)
    return ExitCodeFor(output.CodeInternal)
}

type handlerFn func(r *Router, rest []string) int

var handlers = map[string]handlerFn{}

func RegisterHandler(sub string, fn handlerFn) { handlers[sub] = fn }

func writeJSONError(w io.Writer, code output.ErrorCode, msg string) {
    _ = output.WriteFailure(w, code, msg, nil)
}

// ExitCodeFor maps an ErrorCode to a fixed exit code. The mapping is
// one-to-one and a contract with agents.
func ExitCodeFor(code output.ErrorCode) int {
    switch code {
    case output.CodeQuery:      return 1
    case output.CodeConfig:     return 2
    case output.CodeConnection: return 3
    case output.CodeAuth:       return 4
    case output.CodeSafety:     return 5
    case output.CodeTimeout:    return 6
    case output.CodePermission: return 7
    }
    return 99
}

var _ = os.Exit // imported for future use
```

```go
func main() {
    fs := flag.NewFlagSet("sql-cli", flag.ContinueOnError)
    fs.SetOutput(io.Discard) // we never write parse errors to stderr; emit JSON instead
    var flagDSN string
    var showVersion, showHelp bool
    fs.StringVar(&flagDSN, "dsn", "", "MySQL DSN in mysql:// form")
    fs.BoolVar(&showVersion, "version", false, "print version and exit")
    fs.BoolVar(&showHelp, "help", false, "print help and exit")
    if err := fs.Parse(os.Args[1:]); err != nil {
        writeErrJSON(os.Stdout, output.CodeConfig, "flag parse: "+err.Error())
        os.Exit(cli.ExitCodeFor(output.CodeConfig))
    }
    if showHelp { cli.PrintHelp(os.Stdout); os.Exit(0) }
    if showVersion { cli.PrintVersion(os.Stdout); os.Exit(0) }

    // Resolve DSN: flag > env.
    dsn, err := config.Resolve(flagDSN, os.Getenv("SQL_CLI_DSN"))
    if err != nil {
        writeErrJSON(os.Stdout, output.CodeConfig, err.Error())
        os.Exit(cli.ExitCodeFor(output.CodeConfig))
    }

    // Open the database; classify connection-time errors.
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    db, err := mysqldrv.Open(ctx, dsn)
    if err != nil {
        code, msg, details := mysqldrv.ClassifyError(err, "")
        _ = output.WriteFailure(os.Stdout, code, msg, details)
        os.Exit(cli.ExitCodeFor(code))
    }
    defer db.Close()

    // Register subcommand handlers.
    cli.RegisterHandler("databases", func(r *cli.Router, _ []string) int {
        ow := &stdoutOW{stdout: r.Stdout}
        if err := command.Databases(ctx, sqlDBAdapter{db}, ow); err != nil {
            return handleCmdErr(r.Stdout, err)
        }
        return 0
    })
    cli.RegisterHandler("tables", func(r *cli.Router, rest []string) int {
        if len(rest) != 1 {
            writeErrJSON(r.Stdout, output.CodeConfig, "tables: exactly one argument (database name) is required")
            return cli.ExitCodeFor(output.CodeConfig)
        }
        ow := &stdoutOW{stdout: r.Stdout}
        if err := command.Tables(ctx, sqlDBAdapter{db}, rest[0], ow); err != nil {
            return handleCmdErr(r.Stdout, err)
        }
        return 0
    })
    cli.RegisterHandler("describe", func(r *cli.Router, rest []string) int {
        if len(rest) != 1 {
            writeErrJSON(r.Stdout, output.CodeConfig, "describe: exactly one argument (<db>.<table>) is required")
            return cli.ExitCodeFor(output.CodeConfig)
        }
        ow := &stdoutOW{stdout: r.Stdout}
        if err := command.Describe(ctx, sqlDBAdapter{db}, rest[0], ow); err != nil {
            return handleCmdErr(r.Stdout, err)
        }
        return 0
    })
    cli.RegisterHandler("query", func(r *cli.Router, rest []string) int {
        var sqlText string
        var readStdin bool
        if len(rest) == 1 && rest[0] == "-" { readStdin = true }
        if len(rest) == 1 && !readStdin { sqlText = rest[0] }
        if len(rest) == 0 {
            // no positional; check for --stdin
            for _, a := range os.Args[1:] { if a == "--stdin" { readStdin = true; break } }

        ow := &stdoutOW{stdout: r.Stdout}
        if err := command.Query(ctx, sqlDBAdapter{db}, sqlText, readStdin, ow, r.Stderr); err != nil {
            return handleCmdErr(r.Stdout, err)
        }
        return 0

    router := &cli.Router{Stdout: os.Stdout, Stderr: os.Stderr, DSN: dsn}
```

# sql-cli

A small, single-binary CLI that lets AI agents query MySQL with structured
JSON output, fixed exit codes, and a default read-only posture.

## Install

```bash
go install github.com/qiezi999/sql-cli/cmd/sql-cli@latest
```

## Usage

```bash
# Provide a DSN via flag or env var
export SQL_CLI_DSN="mysql://user:pass@host:3306/db?parseTime=true"

# List databases
sql-cli databases

# List tables in a database
sql-cli tables mydb

# Describe a table
sql-cli describe mydb.users

# Run a SELECT
sql-cli query "SELECT id, name FROM users LIMIT 10"

# Read SQL from stdin (heredoc-safe)
sql-cli query - <<'SQL'
SELECT COUNT(*) AS c
FROM users
WHERE created_at > NOW() - INTERVAL 7 DAY
SQL
```

## DSN format

`mysql://user:password@host:port/dbname?param=value`

The driver-native DSN form (`user:pass@tcp(host:port)/db`) is **not**
accepted; use the `mysql://` URL form. The port segment is required.

## Error codes and exit codes

| code                  | exit |
|-----------------------|------|
| `QUERY_ERROR`         | 1    |
| `CONFIG_ERROR`        | 2    |
| `CONNECTION_ERROR`    | 3    |
| `AUTH_ERROR`          | 4    |
| `SAFETY_BLOCKED`      | 5    |
| `TIMEOUT`             | 6    |
| `PERMISSION_DENIED`   | 7    |
| `INTERNAL_ERROR`      | 99   |

`message` is human-facing prose and is **not** a contract. Branch on
`code`, `mysql_error_code`, and the `details` keys only.

## Out of scope for v1.0

`--allow-write`, transactions, `tx` subcommand, YAML config,
table/csv/tsv output, `explain`/`analyze`/`status`, MCP server mode,
other database drivers, plugin system, parameter binding, `--timeout`
flag.

## Defence in depth

The keyword scanner catches common write attempts (`INSERT`, `UPDATE`,
`DELETE`, `DROP`, `CREATE`, `ALTER`, `TRUNCATE`, `GRANT`, `REVOKE`,
`RENAME`, `REPLACE`) but is bypassable. **Always connect with a
read-only MySQL account.** Recommended:

```sql
CREATE USER 'agent'@'%' IDENTIFIED BY '...';
GRANT SELECT ON mydb.* TO 'agent'@'%';
```
